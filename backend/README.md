# Sistema de Gestión de Egresados - Backend

## Requisitos

- Node.js
- npm
- MongoDB Community Server
- MongoDB Compass (opcional)

## Configuración

1. Instalar dependencias:

npm install

2. Copiar:

.env.example

como:

.env

3. Verificar que MongoDB esté ejecutándose.

4. Cargar los datos iniciales:

npm run seed

5. Iniciar el backend:

npm run dev

El servidor estará disponible en:

http://localhost:3000

Para comprobarlo:

http://localhost:3000/api/salud

## Frontend

Abrir:

frontend/index.html

utilizando Live Server.
