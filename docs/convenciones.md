# Convenciones de programación

Este documento establece las reglas de escritura que deben utilizarse en todo el proyecto.

## 1. Idioma

Los nombres de variables, funciones, archivos y propiedades estarán escritos en español.

No se utilizarán tildes, espacios ni la letra ñ dentro de los identificadores.

Correcto:

```js
const anioGraduacion = 2026;
const numeroIdentificacion = "1-1111-1111";
